

# SolPay

A decentralized payment solution built on the Solana blockchain, enabling fast and low-cost cryptocurrency transactions.

##  Development Status

**This project is currently under active development and deployed on Solana Devnet only.**

SolPay is not yet ready for production use. Significant work remains to be completed before mainnet deployment. Features, APIs, and functionality are subject to change without notice.

## Features

- Fast payment processing leveraging Solana's high throughput
- Low transaction fees
- Decentralized architecture
- User-friendly payment interface

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- Solana CLI tools
- A Solana wallet configured for Devnet

### Installation

```bash
git clone https://github.com/yourusername/solpay.git
cd solpay
npm install
```

### Configuration

Configure your environment to use Solana Devnet:

```bash
solana config set --url devnet
```

### Running the Application

```bash
npm start
```
